Avatar Editor Bald Neon Test

A private test copy of the Avatar Editor, loaded with the bald Neon morph build (Neon_Ultra_Bald_AniimoMorphs_v01.glb). The base stays bald: hair is a separate GLB (Neon_Hair_Braids_v01.glb) attached at runtime and on by default, and the baby-hair trio (Neon_BabyHair_Shell_v01.glb) is a second attachment whose three styles — Soft Swoop, Delicate Curls, Feathered Wisps — are meshes inside the one shell GLB, cycled by visibility. Both are modular wearables, never baked into the base. Drag to orbit, scroll to zoom. Every slider drives the matching morph target on all 18 meshes with damped, smoothed influence: 50 is neutral, 0 and 100 push the morph to its negative and positive extremes.

Camera presets reframe without touching your morphs. Lighting presets restyle the 3-point studio rig (key / fill / rim) and the stage backdrop only — the model and its materials are unchanged.

Console — history & symmetry

Paired features — eyes, nose, ears — get an L and an R slider. While Symmetrical is on they mirror each other; switch to Asymmetrical to push one side past the other (the morph itself is shared, so the split shows as a fine lateral offset on that feature). Both sides are stored in the Face ID.

Hair attachment

Baby-hair shell — Neon_BabyHair_Shell_v01.glb

One shell GLB, three style meshes plus an invisible holder sitting 0.5–1.0 mm off the forehead skin. Picking a style shows that mesh and hides the other two; the shell is placed off the head itself and does not move with the braids or their transform.

Hair transform — fine adjust

Second Life–style wearable adjust for the hair attachment: offset in metres, scale as a multiplier, applied live. Reset returns offset [0, 0, 0], scale [1, 1, 1].

Face ID preset: version 1, base “A”, blend “neutral”, all 18 morphs stored as 0–1 values, the symmetry mode and per-pair L/R values, the hair as its own GLB reference with offset and scale, the baby-hair style key (babyHair), plus the fixed test defaults for skin, iris, outfit, symbiont, and expression.

Import Face ID

Test model: bald Neon, T-pose, ~0.99 m, 18 meshes, each carrying the same 18 morph targets. Morph influence = (slider − 50) / 50, eased toward its target every frame (damping) so scrubbing stays smooth across all 18 meshes. Hair: Neon braids, 12 meshes, a separate GLB attached to the avatar root at runtime — the bald base file is unchanged. Baby-hair shell: a separate GLB attached at the root, three style meshes cycled by visibility, holder 0.5–1.0 mm off the skin.
