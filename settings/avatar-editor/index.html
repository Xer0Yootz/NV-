Studio lighting

Two separate control groups on this screen: Camera & Movement (focus presets, turntable, idle return) is run by the editor's own camera module — editor-local controls, not shared with any game screen — while appearance (morphs, hair, baby-hair shell) lives in the console panel, and model / animation / lighting sit in their own group above. Camera presets reframe without touching your morphs; lighting presets restyle the 3-point studio rig (key / fill / rim) and the stage backdrop only.

Console — appearance · history & symmetry

Paired features — eyes, nose, ears — get an L and an R slider. While Symmetrical is on they mirror each other; switch to Asymmetrical to push one side past the other (the morph itself is shared, so the split shows as a fine lateral offset on that feature). Both sides are stored in the Face ID.

Hair attachment

Baby-hair shell — Neon_BabyHair_Shell_v01.glb

One shell GLB, three style meshes plus an invisible holder sitting 0.5–1.0 mm off the forehead skin. Picking a style shows that mesh and hides the other two; the shell is placed off the head itself and does not move with the braids or their transform.

Hair transform — fine adjust

Second Life–style wearable adjust for the hair attachment: offset in metres, scale as a multiplier, applied live. Reset returns offset [0, 0, 0], scale [1, 1, 1].

Face ID preset: version 1, base “A”, blend “neutral”, all 18 morphs stored as 0–1 values, the symmetry mode and per-pair L/R values, the hair as its own GLB reference with offset and scale, the baby-hair style key (babyHair), plus the fixed defaults for skin, iris, outfit, symbiont, and expression.

Import Face ID

Default model: Rigged Neon, 1 mesh, 65 joints, clips “idle” (~15.3 s, the default loop) and “Psionic Idle” (~5.0 s) via THREE.AnimationMixer. Bald base is still switchable: bald Neon, T-pose, ~0.99 m, 18 meshes, each carrying the same 18 morph targets. Morph influence = (slider − 50) / 50, eased toward its target every frame (damping) so scrubbing stays smooth across all 18 meshes. Hair: Neon braids, 12 meshes, a separate GLB attached to the avatar root at runtime — the bald base file is unchanged. Baby-hair shell: a separate GLB attached at the root, three style meshes cycled by visibility, holder 0.5–1.0 mm off the skin. Rigged Neon: Neon_Ultra_Rigged_Test.glb, Tripo-rigged, 1 skin, 65 joints, clips “idle” (~15.3 s, the default loop) and “Psionic Idle” (~5.0 s) via THREE.AnimationMixer — animation only, no morphs. Idle return: after the adjustable timeout with no input (10 s by default) the camera eases back to the Full Body preset and the default idle loop starts on models that carry animation.
